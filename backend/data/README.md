# Seed Data

`beneficiaries.csv` contains 250 **fully synthetic** beneficiary records generated by `backend/ml/dataset.py`. No real personal data is present.

This file is committed intentionally — it is loaded into the SQLite database automatically on first server start (via the FastAPI lifespan hook), so the app is usable immediately after cloning with no manual setup.

---

**If you replace this file with real beneficiary data, add it to `.gitignore` before committing.**
